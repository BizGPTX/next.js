# Tarot Reader

A polished single-page Next.js tarot experience that draws three unique cards and delivers a warm, text-based reading.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Features

- Full 78-card tarot deck stored in structured code
- Past / Present / Future three-card spread
- Template-based reading generator fallback with coherent interpretations
- Optional card meanings toggle
- Daily card mini-feature
- Copy/share reading action
- Mobile-friendly mystical UI with subtle glow animations
